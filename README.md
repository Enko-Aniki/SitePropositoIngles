## 📌 Sobre o Projeto

O **Propósito do Inglês** é um site educacional que reúne em um só lugar tudo que você precisa para aprender e praticar inglês de forma engajante. A plataforma funciona como um hub central que combina curadoria de conteúdo com aprendizado gamificado.

### O que você encontra aqui:

- 📺 **Hub de Mídias** — filmes, séries, músicas, podcasts e vídeos organizados para estudo
- 📚 **Conteúdo Educacional** — artigos, dicas gramaticais e materiais de referência
- 🎮 **Jogos de Aprendizado** — atividades interativas para fixar vocabulário e gramática

---

## 🎮 Funcionalidades Gamificadas

### 🧩 Quiz
Teste seus conhecimentos com perguntas de múltipla escolha sobre vocabulário, gramática e interpretação de texto.

### 🖱️ Drag and Drop
Organize palavras e frases arrastando-as para os lugares corretos — ideal para fixar estruturas de frases e vocabulário em contexto.

### 🪢 Hangman (Forca)
O clássico jogo da forca com palavras em inglês para treinar ortografia e vocabulário de forma divertida.

## 🚀 Como Rodar Localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/) 18+
- npm, yarn ou pnpm

### Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Enko-Aniki/SitePropositoIngles.git
   cd SitePropositoIngles
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   # ou
   pnpm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou
   yarn dev
   # ou
   pnpm dev
   ```

4. Acesse [http://localhost:3000](http://localhost:3000) no navegador.
